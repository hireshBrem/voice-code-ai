# VoiceCodeX

AI voice agent that chats with your codebase.

## Overview

VoiceCodeX lets you have natural voice conversations about any GitHub repository. Ask questions, explore code structure, and understand projects through spoken dialogue.

## Features

### GitHub Integration
Connect any public or private GitHub repository. VoiceCodeX fetches and indexes your codebase, making it available for intelligent conversation.

### ElevenLabs Voice Agent
Powered by ElevenLabs conversational AI for natural, low-latency voice interactions. Speak naturally and get spoken responses about your code.

### Ngrok Server
Uses ngrok to expose local webhook endpoints, enabling real-time communication between ElevenLabs and your codebase tools.
